계층별 책임:

📊 Presentation
  ┗ 목표: UI 렌더링만
  ┗ 파일: *.dart (screen, widget)
  ┗ 허용: Widget 빌드, 사용자 이벤트
  ┗ 금지: 비즈니스 로직, API 호출

📊 Application  
  ┗ 목표: 상태 관리
  ┗ 파일: *_vm.dart (ViewModel), providers.dart
  ┗ 허용: StateNotifier, UseCase 호출
  ┗ 금지: 직접 API/DB 접근

📊 Domain
  ┗ 목표: 비즈니스 로직
  ┗ 파일: *.dart (entity, service, use_case)
  ┗ 허용: 순수 Dart, 로직 구현
  ┗ 금지: 외부 라이브러리 (Flutter, http)

📊 Data
  ┗ 목표: 외부 데이터 접근
  ┗ 파일: *_repository.dart, *_client.dart, *_model.dart
  ┗ 허용: API 호출, Database, JSON 변환
  ┗ 금지: 비즈니스 로직

================================================================================

파일 명명 규칙:

Presentation:
  - screens: *_screen.dart (e.g., character_search_screen.dart)
  - widgets: *_widget.dart (e.g., character_card.dart)

Application:
  - viewmodels: *_vm.dart (e.g., character_search_vm.dart)

Domain:
  - entities: *.dart (e.g., character.dart)
  - services: *_service.dart (e.g., timeline_service.dart)
  - use_cases: *_uc.dart (e.g., search_character_uc.dart)

Data:
  - repositories: *_repository.dart
  - data_sources: *_client.dart, *_service.dart
  - models: *_model.dart
