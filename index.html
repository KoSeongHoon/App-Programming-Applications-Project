🎮 던전앤파이터 플래너

효율적인 주간 컨텐츠 관리를 위한 모바일 앱
고성훈 | 앱 프로그래밍 응용

📋 기획: 비전 & 문제 정의

🚨 현재의 문제점

  • 주간 컨텐츠 관리
    상급던전 7개, 레기온 2개, 레이드 3개 (총 12개) 관리 필요
  • 반복적 확인 작업
    매주 목요일마다 초기화되는 컨텐츠 확인
  • 다중 캐릭터 관리
    여러 캐릭터 클리어 상태 추적 불편

👥 타겟 사용자

  • 던파 게이머
    주간 컨텐츠를 효율적으로 관리
  • 멀티 플레이어
    여러 캐릭터 운영
  • 시간 효율 추구
    게임 진행을 체계적으로 관리

💡 우리의 솔루션

한 앱에서 모든 캐릭터의 주간 컨텐츠 클리어 현황을
한눈에 확인하고 관리한다

🏗️ 설계: Clean Architecture

Presentation Layer (UI) ↓ Application Layer (ViewModel) ↓ Domain Layer (Entity) ↓ Data Layer (API/DB)

📦 기술 스택

  • Frontend: Flutter 3.41.9
  • Language: Dart 3.11.5
  • State Mgmt: Riverpod
  • Database: SQLite
  • API: Neople API
  • Architecture: Clean 4-Layer

📱 실제 앱 화면: 검색 기능

✨ 주요 기능

  • Neople API 연동 - 공식 게임 DB에서 캐릭터 검색
  • 서버 선택 - 원하는 서버별로 필터링
  • 실시간 검색 - 캐릭터명 입력 시 즉시 결과 표시
  • 캐릭터 추가 - 선택한 캐릭터를 플래너에 추가

📋 실제 앱 화면: 주간 컨텐츠 플래너

✨ 주간 컨텐츠 관리

  • 상급던전 7개 - 최후의 과업, 배교자의 성, 별거북 대서고 등
  • 레기온 2개 - 아포칼립스, 미의 여신 베누스
  • 레이드 3개 - 디레지에, 이내황혼전, 만들어진 신 나벨 (노말/하드)
  • 클리어 상태 - ✅/❌ 표시로 진행 상황 한눈에 파악
