📋 기획: 비전 & 문제 정의

🚨 현재의 문제점

  • 주간 컨텐츠 관리
    상급던전 7개, 레기온 2개, 레이드 3개 (총 12개) 관리 필요
  • 반복적 확인 작업
    매주 목요일마다 초기화되는 컨텐츠 확인
  • 다중 캐릭터 관리
    여러 캐릭터 클리어 상태 추적 불편

👥 타겟 사용자

  • 던파 게이머

  • 멀티 플레이어
    여러 캐릭터 운영
  • 시간 효율 추구
    게임 진행을 체계적으로 관리

💡 우리의 솔루션

한 앱에서 모든 캐릭터의 주간 컨텐츠 클리어 현황을
한눈에 확인하고 관리한다

🏗️ 설계: Clean Architecture

Presentation Layer (UI) ↓ Application Layer (ViewModel) ↓ Domain Layer (Entity) ↓ Data Layer (API/DB)

📦 기술 스택

  • Frontend: Flutter 3.41.9
  • Language: Dart 3.11.5
  • State Mgmt: Riverpod
  • Database: SQLite
  • API: Neople API
  • Architecture: Clean 4-Layer
