01 — 비전 & 문제

프로젝트 개요

🎯 비전

던파 유저들의 다중 캐릭터 관리를 효율적으로 돕고, 주간 컨텐츠 완료 현황을 시각적으로 추적

⚠️ 문제

• 다중 캐릭터 관리의 복잡성
• 수동 기록의 번거로움
• 실시간 정보 조회 어려움

👥 타겟 유저

• 다중 캐릭터 플레이 유저
• 길드/모험단 리더
• 효율적 플레이 추구 유저

🎮 던전앤파이터 플레이 현황

• 글로벌 플레이어: 약 1,000만명
• 한국 서버 활성 유저: 약 200만명
• 다중 캐릭터 플레이율: 약 70%

08 — 시행착오 & 해결

Neople API 관련 이슈

⏰ 타임라인 조회 시점
문제: 조회 시점을 "전주 목요일~다음 목요일"로 제한

해결: API는 과거~현재까지만 제공. 조회 시점을 "과거부터 현재"로 변경
👥 모험단 정보 부재
문제: API에서 모험단 정보 직접 제공 X

해결: 캐릭터 기본정보 조회 → 모험단명 추출 → DB 저장 → DB에서 모험단별 검색
