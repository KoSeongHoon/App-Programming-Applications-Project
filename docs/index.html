01 — 비전 & 문제

프로젝트 개요

⚠️ 문제

• 주간 던전 클리어 현황을 일일히 체크하기가 어려움
• 여러 캐릭터를 육성 중일땐 더더욱 어려움
• 매번 접속해서 확인하는게 번거로움

🎯 비전

던파 유저들의 다중 캐릭터 관리를 효율적으로 돕고, 주간 컨텐츠 완료 현황을 시각적으로 추적

👥 타겟 유저

• 던전앤파이터 플레이 유저
• 다중 캐릭터 플레이 유저
• 모바일로 주간 컨텐츠를 관리하고 싶은 유저

09 — 시행착오 & 해결

Neople API 관련 이슈

⏰ 타임라인 조회 시점
문제: 조회 시점을 "전주 목요일~다음 목요일"로 제한

해결: API는 과거~현재까지만 제공. 조회 시점을 "과거부터 현재"로 변경
👥 모험단 정보 부재
문제: API에서 모험단 정보 직접 제공 X

해결: 캐릭터 기본정보 조회 → 모험단명 추출 → DB 저장 → DB에서 모험단별 검색
