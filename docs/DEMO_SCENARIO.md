# 🎬 30초 데모 시나리오 (발표용)

**목표**: 30초 안에 앱의 핵심 기능을 임팩트 있게 시연  
**시간 제한**: 엄격히 30초 (준비: 5초, 시연: 25초)

---

## 📹 **최종 30초 데모 시나리오**

### **[준비 단계: 5초]**

```
앱 미리 설치 및 실행
- 홈 화면 대기
- 캐릭터 검색 화면으로 이동
- 검색창 활성화 (포커스된 상태)
```

### **[시연 단계: 25초]**

#### **0:00-0:08 | "캐릭터 검색" (임팩트 있는 시작)**

```
발표자 대사:
"먼저 캐릭터를 검색합니다."

액션:
1. 검색창에 "우르반" 입력 (3초)
   → 빠르고 명확하게 입력
   
2. 검색 버튼 탭 (1초)
   → 결과 로딩 시작
   
3. 검색 결과 화면 표시 (4초)
   → 캐릭터 이미지
   → 이름, 직업, 레벨
   → "플래너에 추가" 버튼 보임
```

**화면 흐름**:
```
[검색창]          → [로딩중]       → [검색결과]
"우르반 입력"      "요청 중..."      "우르반"
                                   "귀검사 Lv.100"
                                   [플래너에 추가]
```

---

#### **0:08-0:16 | "플래너 추가" (기능 시연)**

```
발표자 대사:
"플래너에 추가하면, 주간 컨텐츠 체크리스트가 생깁니다."

액션:
1. "플래너에 추가" 버튼 탭 (2초)
   → 성공 메시지 나옴
   
2. 홈 화면으로 돌아가기 (1초)
   → 뒤로 가기 또는 탭 전환
   
3. 플래너 화면 표시 (5초)
   → 캐릭터 카드 보임
   → 상급던전 체크리스트
   → 레이드 (노멀/하드)
   → 레기온 (체크박스)
```

**화면 흐름**:
```
[캐릭터카드]
"우르반 (귀검사 Lv.100)"

[주간 컨텐츠]
☑ 최후의 과업
☐ 배교자의 성
☐ 도시의 하층부
....
☐ 노말 레이드
☑ 하드 레이드
```

---

#### **0:16-0:25 | "모험단 검색" (마무리 - 가장 임팩트 있음!)**

```
발표자 대사:
"그리고 모험단 멤버를 한 번에 검색할 수 있습니다!"

액션:
1. 서버 필터 변경 (1초)
   → 드롭다운에서 "모험단" 선택
   
2. 모험단명 입력 (2초)
   → "우리모험단" 입력
   → 빠르게 입력
   
3. 검색 버튼 탭 (1초)
   
4. 모험단 멤버 목록 표시 (5초)
   → 여러 캐릭터 카드
   → 동일한 모험단 확인
   → 스크롤 해서 여러 멤버 보임
   
5. 화면 클로즈 (1초)
```

**화면 흐름**:
```
[필터: "모험단"]
[검색창: "우리모험단"]

[결과]
"검색 결과: 5개"
├─ [우르반] 귀검사 Lv.100
├─ [검객] 소울마스터 Lv.98
├─ [레이저] 런처 Lv.95
├─ [화염검] 귀검사 Lv.92
└─ [나이트] 나이트 Lv.88
```

## 💡 **임팩트 있는 데모 팁**

### **1. 스토리텔링**

```
❌ 나쁜 예:
"이건 캐릭터 검색이고, 이건 플래너이고..."

✅ 좋은 예:
"게임을 할 때 여러 캐릭터를 관리해야 하잖아요?
 이 앱은 한 번에 다 할 수 있습니다!"
```

### **2. 손 제스처**

```
검색 할 때: 검색창을 손가락으로 가리키며
"검색합니다" (손 제스처)

플래너 추가: "추가" 버튼을 손가락으로 탭하며
"이렇게 간단하게" (손짓)

모험단 검색: 여러 카드를 스와이프하며
"전부 한 번에!" (큰 제스처)
```

### **3. 음성 강조**

```
"캐릭터를 (평상적) 검색합니다.
 플래너에 (강조) 추가하면,
 (강조) 주간 컨텐츠가 (강조) 자동으로 나옵니다!"
```

### **4. 속도 조절**

```
✓ 검색 입력: 보통 속도 (사용자가 읽을 시간)
✓ 로딩 대기: 자연스럽게 (서둘지 않기)
✓ 결과 보기: 천천히 (각 화면을 2-3초)
✓ 마무리: 빠르게 (시간 부족 방지)
```
