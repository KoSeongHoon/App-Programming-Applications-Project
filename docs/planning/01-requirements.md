# 던전앤파이터 플래너 앱 — 요구사항 분석

## 📋 핵심 사용자 시나리오 (3개)

---

## 시나리오 1️⃣: 캐릭터 검색 및 타임라인 조회

**사용자**: 앱을 열어서 나의 캐릭터 타임라인 조회  
**목표**: Neople API에서 캐릭터의 최근 활동 기록(타임라인) 조회 및 저장

### 사용 흐름
```
1. 앱 열기
2. "캐릭터 검색" 탭 진입
3. 캐릭터 닉네임 입력 (예: "고성훈")
4. 서버 선택 (한국 서버만)
5. Neople API 조회
6. 타임라인 데이터 조회 (최근 90일)
7. 데이터 로컬 저장
```

### 주요 기능
- ✅ 캐릭터 검색 (닉네임 입력)
- ✅ Neople API 캐릭터 기본정보 조회
- ✅ Neople 타임라인 API 조회 (110레벨 이상)
- ✅ 타임라인 데이터 로컬 저장 (SQLite/Hive)
- ✅ 새로고침 버튼 (수동 데이터 갱신)
- ✅ API 오류/네트워크 오류 시 알림

---

## 시나리오 2️⃣: 주간 콘텐츠 플래너 자동 업데이트

**사용자**: 캐릭터를 선택한 후 주간 콘텐츠 클리어 현황 자동 확인  
**목표**: 타임라인 데이터를 분석하여 주간 콘텐츠 클리어 여부를 자동 감지하고 플래너에 반영

### 사용 흐름
```
1. 캐릭터 선택 (저장된 캐릭터 또는 새로 검색)
2. "플래너" 탭 진입
3. 주간 콘텐츠 목록 표시
   ├─ 일일 콘텐츠 (던전, 레이드)
   └─ 주간 콘텐츠 (주간 특별 던전)
4. 타임라인에서 클리어 기록 자동 감지
5. 체크박스 자동 표시
   ☑ 에픈 성 (10:30 클리어 감지)
   ☐ 탈리스만 (미클리어)
   ☑ 황금 괴물 (어제 클리어)
6. 수동 조정 가능 (체크/언체크)
```

### 주요 기능
- ✅ 주간 콘텐츠 카탈로그 (일일/주간 모두)
- ✅ 타임라인 코드/텍스트 분석 (클리어 판정)
- ✅ 자동 매칭 로직 (타임라인 ↔ 플래너)
- ✅ 체크리스트 UI (체크박스 형식)
- ✅ 수동 체크/언체크 기능
- ✅ 주간 리셋 (일요일 자동 초기화)

---

## 시나리오 3️⃣: 주간 진행도 확인 및 통계

**사용자**: 이번 주 콘텐츠 클리어 현황을 한눈에 파악  
**목표**: 체크리스트 기반 진행도 표시 및 기본 통계 제공

### 사용 흐름
```
1. "플래너" 탭에서 진행도 확인
2. 진행도 표시
   총 콘텐츠: 15개
   클리어: 8개
   진행률: 53% (또는 ████░░░░)
3. 마지막 업데이트 시간 표시
4. "새로고침" 버튼으로 타임라인 재조회
5. 주간 리셋 예정 시간 표시 (일요일 자정)
```

### 주요 기능
- ✅ 진행도 바 또는 퍼센트 표시
- ✅ 클리어/미클리어 개수 표시
- ✅ 마지막 업데이트 타임스탬프
- ✅ 타임라인 최근 클리어 기록 표시 (선택사항)
- ✅ 주간 리셋 카운트다운
