# 던전앤파이터 플래너 앱 — 비전 & 목표

## 📌 프로젝트 개요

**던전앤파이터 플래너**는 Neople API의 타임라인 데이터를 활용하여 플레이어의 **주간 콘텐츠 클리어 현황을 자동으로 추적**하고 관리할 수 있는 모바일 플래너 앱입니다.

---

## 🎯 핵심 비전

> **"던전앤파이터 플레이어가 타임라인을 통해 주간 콘텐츠 클리어 현황을 한눈에 파악하고, 자동으로 업데이트되는 플래너로 효율적으로 콘텐츠를 관리할 수 있는 앱"**

---

## 🔑 주요 목표

### 1단계: MVP (최소 기능 제품, 6주)
- [x] Neople API 타임라인 데이터 수집
- [x] 주간 콘텐츠(일일/주간) 클리어 기록 자동 감지
- [x] 플래너에 자동 반영 (체크리스트)
- [x] 한국 서버 캐릭터 검색 및 조회
- [x] 주간 리셋 (일요일 자동 초기화)

### 2단계: 향후 배포 (추후)
- [ ] 강화 계획 모듈
- [ ] 캐릭터 능력치 대시보드
- [ ] 아바타 강화 계획
- [ ] 멀티 서버 지원
- [ ] 멀티 캐릭터 동시 관리

---

## 📊 프로젝트 일정

- **개발 기간**: 10주차 ~ 15주차 (6주)
- **중간 발표**: 12주차 (진행도 50%)
- **최종 발표**: 15주차 (완성도 100%)

---

## 👥 사용자 페르소나

### 주요 사용자
- **이름**: 고성훈 (개발자)
- **게임 경험**: 던전앤파이터 활동 플레이어
- **기술 수준**: 프로그래밍 경험 있음
- **사용 목적**: 개인의 주간 콘텐츠 클리어 현황 추적

### 추후 배포 시 타겟
- 주간 콘텐츠 체계적으로 관리하려는 플레이어
- 클리어 현황을 효율적으로 추적하고 싶은 유저

## 🛠️ 기술 스택

| 계층 | 기술 |
|------|------|
| **UI Framework** | Flutter (Dart) |
| **상태 관리** | Provider / Riverpod (선택 예정) |
| **API 연동** | Neople OpenAPI (RESTful - 타임라인) |
| **로컬 저장소** | SQLite / Hive |
| **IDE/환경** | VS Code + Flutter SDK |
| **배포 대상** | iOS / Android |

## 📈 성공 지표

| 지표 | 목표 |
|------|------|
| **API 연동** | Neople 타임라인 API 완벽 활용 |
| **자동 감지** | 타임라인 → 플래너 업데이트 < 3초 |
| **UI 반응성** | 화면 로딩 < 2초 |
| **코드 품질** | Unit Test 커버리지 > 50% |

## ⚠️ 제약사항

- **Neople API 한계**: 타임라인은 최근 90일만 제공, 110레벨 이상만 조회 가능
- **서버**: 현재 한국 서버만 지원
- **인증**: Neople API Key 필수 (사용자가 발급)
- **배포**: 개인 프로젝트 목적 → 상업적 이용 불가
