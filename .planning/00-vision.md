# 던전앤파이터 플래너 앱 — 비전 & 목표

## 📌 프로젝트 개요
**던전앤파이터 플래너**는 Neople API를 활용하여 플레이어의 캐릭터 정보를 관리하고, 장비 강화/아바타 강화 계획을 세우며, 최근 활동 기록을 추적할 수 있는 개인 플래너 앱입니다.

---

## 🎯 핵심 비전
> **"던전앤파이터 플레이어가 캐릭터 정보를 효율적으로 관리하고, 강화 계획을 세우며, 게임 활동 기록을 추적할 수 있는 모바일 앱"**

---

## 🔑 주요 목표

### 1단계: MVP (최소 기능 제품, 6주)
- [x] 캐릭터 기본 정보 조회 (Neople API)
- [x] 캐릭터별 능력치 대시보드
- [x] 최근 활동 기록 조회 (타임라인 API)
- [x] 장비 강화 계획 관리 (확률/비용 계산)
- [x] 아바타 강화 계획 관리

### 2단계: 향후 배포 (추후)
- [ ] 멀티 캐릭터 관리
- [ ] 커뮤니티 공유 기능
- [ ] 사용자 비교 기능
- [ ] 알림 기능 (강화 일정 알림 등)

---

## 📊 프로젝트 일정
- **개발 기간**: 10주차 ~ 15주차 (6주)
- **중간 발표**: 12주차 (진행도 50%)
- **최종 발표**: 15주차 (완성도 100%)

---

## 👥 사용자 페르소나

### 주요 사용자
- **이름**: 고성훈 (개발자)
- **게임 경험**: 던전앤파이터 활동 플레이어
- **기술 수준**: 프로그래밍 경험 있음
- **사용 목적**: 개인의 캐릭터 강화 계획 및 활동 기록 추적

### 추후 배포 시 타겟
- 던전앤파이터 장비/아바타 강화 활동가
- 다중 캐릭터 플레이 플레이어
- 효율적인 강화 계획을 선호하는 유저

## 🛠️ 기술 스택

| 계층 | 기술 |
|------|------|
| **UI Framework** | Flutter (Dart) |
| **상태 관리** | Provider / Riverpod (선택 예정) |
