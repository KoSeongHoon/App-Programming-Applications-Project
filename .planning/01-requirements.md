# 던전앤파이터 플래너 앱 — 요구사항 분석

## 📋 핵심 사용자 시나리오 (3개)

---

## 시나리오 1️⃣: 캐릭터 정보 확인

**사용자**: 일일 로그인 후 캐릭터 상태 확인  
**목표**: 캐릭터의 현재 능력치, 장비 정보를 빠르게 파악

### 사용 흐름
```
1. 앱 열기
2. 캐릭터 닉네임 입력 (또는 저장된 캐릭터 선택)
3. Neople API 조회
4. 대시보드 표시
   - 캐릭터 기본정보 (직업, 레벨, 경험치)
   - 주요 능력치 (STR, DEX, VIT, INT, MEN, WIL)
   - 장착 장비 정보
   - 최근 업데이트 시간
```

### 주요 기능
- ✅ 캐릭터 검색 (닉네임으로, 서버 선택)
- ✅ Neople API 자동 연동
- ✅ 캐릭터 저장 (앱 재시작 후에도 유지)
- ✅ 새로고침 버튼 (수동 업데이트)
- ✅ API 오류 시 알림

---

## 시나리오 2️⃣: 장비 강화 계획 세우기

**사용자**: 이번 주 장비 강화 계획을 세우기 위해 강화 비용 계산  
**목표**: 현재 강화도에서 목표 강화도까지의 필요 재료/비용/실패율 계산

### 사용 흐름
```
1. 캐릭터 선택
2. "강화 계획" 탭 진입
3. 현재 장비 강화도 입력 (수동 입력)
4. 목표 강화도 설정
5. 강화 확률/비용 계산 결과 표시
   - 필요 골드/재료 수량
   - 예상 성공율 및 실패 시 손실
   - 주간 획득 가능량 비교
6. 계획 저장
```

### 주요 기능
- ✅ 현재 장비 강화도 입력 (사용자 입력)
- ✅ 강화 확률 테이블 (게임 공식 데이터 기반)
- ✅ 비용 계산 로직 (골드, 강화석, 재료)
- ✅ 성공/실패 시뮬레이션
- ✅ 계획 저장 및 진행도 추적

---

## 시나리오 3️⃣: 최근 활동 기록 확인

**사용자**: 최근에 무엇을 했는지 활동 로그 확인  
**목표**: Neople 타임라인 API를 통해 최근 던전 클리어, 아이템 획득 등의 활동 기록 조회

### 사용 흐름
```
1. 캐릭터 선택
2. "활동 기록" 탭 진입
3. Neople 타임라인 API 조회
4. 최근 활동 리스트 표시
   - 던전 클리어 기록
   - 아이템 획득/삭제
   - 골드 거래
   - 기간: 최근 90일
5. 활동 필터링 (선택사항)
```

### 주요 기능
- ✅ Neople 타임라인 API 연동
- ✅ 활동 기록 조회 (최근 90일)
- ✅ 활동별 필터링 옵션
- ✅ 시간순 정렬
- ✅ 활동 상세 정보 표시

## 🔧 모호한 부분 & 질문

### Q1: 캐릭터 저장 - 로컬만 사용?
**현재 결정**: 로컬 저장소(SQLite/Hive) 사용
- 장점: 인터넷 불필요, 개인정보 보호
- 향후: 배포 시 클라우드 동기화 추가 고려

### Q2: 강화 확률 데이터는?
**현재 결정**: 게임 공식 강화표 데이터(커뮤니티 검증)
- 하드코딩 또는 JSON 파일로 관리
- 패치에 따라 수동 업데이트

### Q3: Neople API 인증 방식?
**현재 결정**: API Key 방식
- 사용자가 developers.neople.co.kr에서 API Key 발급
- 앱 내에 입력하여 저장

### Q4: 타임라인 API 데이터?
**현재 결정**: Neople 타임라인 API로 최근 90일 활동 조회
- 110레벨 이상 캐릭터만 지원
- 활동 필터링 가능
